# 背景音乐（BGM）

本目录下的四首背景音乐，**全部由本仓库的代码从零生成**：

```
程序化乐谱（JS 数据） → 标准 MIDI 文件（.mid） → 自写 PCM 合成器（.wav） → lamejs 编码（.mp3）
```

没有采样素材、没有音源库、没有下载任何第三方音频。所有音符、节奏、音色、混响
都是 `tools/` 下的脚本现算出来的，因此**不存在任何版权问题**，可以随小程序自由分发。

> 原本把四个 `.mid` 也放进了 `public/`，想留个可追溯的乐谱源。
> 但 `hb-sdk remote deploy` 上传时，服务端 CDN 的

> 属于纯死重。删掉后 133 → 129 个文件，上传一次通过。

> 需要乐谱源时跑 `node tools/gen-bgm.mjs` 会重新生成到 `public/bgm/midi/`，
> 但**提交前记得再删掉**，否则提审会被 CDN 拒。

## 循环说明

四首曲子都是**为无缝循环写的**：

- 长度严格等于整数个小节（`小节数 × 每小节拍数 × 60 / BPM`），首尾天然对齐；
- 结尾**没有淡出**，最后一小节的能量与中段持平，接回开头不会掉音量；
- 渲染时多算了一小段"尾巴"（混响 / 延迟的余响），再把这段尾巴**叠加回开头**，
  所以第一拍听到的是"上一轮余响 + 本轮起音"，接缝处的采样差 < 0.03（听不出来）。

在页面里用 `<audio loop>` 或 `AudioBufferSourceNode.loop = true` 直接循环即可，
不需要额外的交叉淡化处理。

| 曲目 | 循环长度 | 小节数 | 每小节拍数 |
| --- | --- | --- | --- |
| minesweeper | 250.435 s | 96 | 4 |
| fruitninja | 247.742 s | 128 | 4 |
| g2048 | 240.000 s | 96 | 4 |
| snake | 240.000 s | 132 | 4 |

## 重新生成

```bash
npm install          # 首次需要，会装 lamejs（纯 JS 的 MP3 编码器）
npm run gen:bgm      # 重新生成全部四首
```

脚本是幂等的：每次都会完整覆盖 `public/bgm/*.mp3`、`public/bgm/midi/*.mid`，
并清理掉格式不符的残留文件。全程约 2 分钟（单线程合成，主要开销在 4 首 × 4 分钟
的 44.1 kHz 逐样本计算）。

中间产物 `.wav`（每首约 21 MB）写在 `.cache/bgm/` 下，**不会**进入 `public/`，
也不会被打包进小程序。

### 只生成某一首

```bash
node tools/gen-bgm.mjs minesweeper
node tools/gen-bgm.mjs snake
```

## 实现结构

```
tools/
├── gen-bgm.mjs          主流程：乐谱 → MIDI → 合成 → MP3
├── gen-images.mjs       图标与封面（与本目录无关，同一套代码风格）
└── lib/
    ├── theory.mjs       音名 / 频率 / 音阶 / 和弦 / 可复现随机数
    ├── songs.mjs        四首曲子的乐谱编排（唯一需要改音乐的地方）
    ├── midi.mjs         MIDI 写入（SMF Format 1，含速度、拍号、标记）
    ├── midi-read.mjs    MIDI 读回（合成器真正读的是解析出来的音符）
    ├── synth.mjs        合成器：振荡器 / ADSR / 滤波 / FM / 混响 / 延迟
    └── png.mjs          PNG 编码 + SDF 画布（图标与封面用）
```

几个刻意的设计：

- **MIDI 不是导出产物，而是中间格式。** 乐谱先写成 `.mid`，再解析回来交给合成器，
  所以 `.mid` 和 `.mp3` 必然一致，不会出现"导出的 MIDI 和听到的不是一首"。
- **相位累加器而不是 `Math.sin(f * i)`。** 后者在几十万个样本后浮点误差累积，
  会产生沙沙的颗粒感。
- **每个单发音符的缓冲区末尾都有 6 ms 淡出。** 否则音符在衰减到零之前被截断，
  会有"哒"的爆音。
- **只在真的超过 0 dBFS 时才做 `tanh` 软限幅**，否则纯线性归一到 -3 dBFS，
  避免无谓的失真。

## 音色设计

| 曲目 | 风格 | 主要音色 |
| --- | --- | --- |
| 扫雷 | 安静、悬疑的极简电子，小调 | 拨弦 / 八音盒式主音 + 低频脉冲 + 稀疏打击 |
| 水果忍者 | 明亮、活泼，大调五声 | 马林巴 / 木琴 + 轻打击 + 弹跳贝斯 |
| 2048 | 轻快不抢注意力，拨弦律动 | 拨弦琶音 + 走动贝斯 + 轻 pad + soft kick/hat |
| 贪吃蛇 | 复古 8-bit | 方波主旋律 + 芯片贝斯 + 噪声鼓 |

四首都是 A/B 两段式（部分带桥段），每首至少 6 条轨道，避免"一个 loop 循环到底"的
单调感。
