# 内置字体

两款字体都来自本机已安装的系统字体，按 **SIL Open Font License** 的常规做法
裁成子集后随小程序分发。裁剪脚本见 `tools/collect-chars.mjs` + `_voice/subfont.py`。

| 文件 | 字体 | 来源 | 子集后大小 | 字符数 |
|---|---|---|---|---|
| `wuxie.woff2` | 吴邪瘦金体 | `吴邪瘦金体[1].TTF` | 350 KB | 1301 |
| `twkai.woff2` | TW-Kai（楷体） | `SYSTEMFONT_0.TTF` | 494 KB | 1301 |

两款都覆盖**简体中文、繁体中文、英文**；TW-Kai 另外覆盖日文假名。

## 为什么必须裁子集

原字体分别是 14.5 MB 和 46.7 MB。小程序包体放不下，手机加载也会卡住。
裁到「界面实际用到的 1301 个字符」后合计 844 KB，这是能接受的量级。

## 为什么是 1301 而不是两万

界面文案是我们自己写的，扫一遍源码就知道用到哪些字（`tools/collect-chars.mjs`）。
用户自己输入的转盘选项、模组变量名用不到这两款字体，会回落到系统字体——
这是刻意的取舍：为了覆盖用户可能输入的任意汉字而多塞 2.7 MB 不值得。

如果以后确实需要覆盖 GB2312 一级字库（3755 个常用字），运行：

```bash
node tools/collect-chars.mjs --full
/c/server/TTS/gsvenv/Scripts/python.exe _voice/subfont.py
```

字体会变成 1.2 MB + 1.7 MB，合计 2.9 MB。改完记得重新评估包体。

## 字体分工

- **吴邪瘦金体** → 标题、品牌名、成绩数字、大按钮。瘦金体笔画细、留白多，
  只在字号 ≥ 18px 时用，小字会糊。
- **TW-Kai** → 正文、说明、列表。楷体比黑体更耐读，长段落不刺眼。
- 两者都通过 `@font-face` + `font-display: swap` 加载，字体没到位时先用系统字体，
  到位后替换，不会白屏。
