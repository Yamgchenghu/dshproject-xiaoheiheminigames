## 为什么没有联网权限

这不是省事，而是一个死结的解法。

原项目申请了 `network`，平台因此把小程序判定为 **server 模式**。
而 server 模式下 `user.getInfo()` 被平台禁用——文档原文：
「第三方小程序进入联网的 server 模式后不能调用本方法获取身份」，
要拿昵称头像必须自建服务端换票。我们没有服务端，所以登录态永远读不到。

三轮「修复」都没用，因为方向本身是错的。
解法是**不申请 `network`** → 回到 host 模式 → `user.getInfo()` 可用 → 真登录。

需要联网的功能迁到另一个小程序（`study` 分支），本分支不申请该权限。

## 关于东海龙珠的合规边界

推币机容易被误判为博彩，所以设计上刻意做了切割：

- **没有充值入口**。币是局内计数，每局固定发放（每日随机 50/80/100/120），不卖、不换、不继承。
- **没有提现/兑换**。彩票只在局内结算成「每币平均彩票」这个分数，不能兑换任何东西。
- **没有概率抽奖变现**。九孔与转奖盘是玩法反馈，不涉及付费抽取。
- **排行榜只展示分数**，无任何奖励发放。

一句话：它长得像街机厅的推币机，但没有任何金钱出入，纯粹是分数游戏。
