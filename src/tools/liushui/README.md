# 流水入杯

> 工具页第三个卡片。原型是 `流水入杯-正式版-v1.0.27.apk`。

## 玩法

上面一个水龙头，下面一个杯子。水一直在滴，**你得画线把水引进杯子里**。

- 水没进杯子 = 洒了，杯子里的水位不涨。
- 杯子里有 200 滴就满，190 滴算达标。
- 一共有 225 滴，滴完就结算。
- 有毒水龙头（紫色）会往旁边滴水，被污染也算失败。

手指在画布上拖动画线，最多画 **3 条**，每条最长 **0.605** 个世界单位
（世界宽 0.6、高 1.0，所以一条线差不多能横穿屏幕）。

## 关卡

14 关，逐关增加障碍：墙、火线、泥地、移动的火焰球。
关卡数据在 `levels.js`，由 `tools/gen-levels.mjs` 生成。

**注意**：不画线的情况下，只有第 1 关能不借助线条过关（221/225 滴）。
这是设计使然——后面几关的出水口被挡住，必须画线导流。

## 物理

从原 APK 的 Java 代码移植过来的，不是重新实现的近似版本：

- 定步长 1/240 秒，带累加器；一帧最多补 12 步（防止切后台回来时“瞬移”）。
- 水滴是圆形刚体，与线段（`Bar`）做连续碰撞检测。
- 线段有 `TAG`：地面、支撑、墙、火线、泥地、玩家画的线。不同 TAG 的
  摩擦、反弹、是否致命都不一样。
- 杯子是一个 U 形，由 3 段 `Bar` 组成（左壁、底、右壁）。

`engine.js` 里导出的常量（`WORLD_W`、`TOTAL_DROPS`、`CUP_FULL_DROPS` …）
和类（`PhysicsWorld`、`GameWorld`、`Bar`、`Drop`）都可以被外部读取，
方便调参和写测试。

## 界面

`screen.js`，一个自绘 canvas 应用：

- 保持 0.6:1.0 的宽高比，用 letterbox 方式适配任意屏幕（不拉伸变形）。
- DPR 上限 2.5，避免高分屏上 fill rate 拖垮帧率。
- 指针事件用 `setPointerCapture`，手指划出画布也不会断线。
- 采样点做抽稀：位移小于 0.004 世界单位的点丢掉，一条线最多 40 个点。

## 与原型 APK 的差异

| 项 | 原 APK | 这里 | 为什么 |
|---|---|---|---|
| 存档 | 本地文件 | 小黑盒云存档 | 换设备能同步 |
| 关卡数 | 更多 | 14 | 保证每一关都经过物理验证，不是凑数 |
| 广告 | 有 | 无 | 小程序不允许，也没必要 |
